# MTGタイマー

GitHub Pages: https://lamy210.github.io/timer/

日本時間（JST）基準のMTG用タイマーです。`public/` 以下をそのまま配信しています。

## 使い方

- MTG開始時刻、会議の長さ、開始前アラーム、終了前アラームを設定
- 開催日は任意。空の場合は開始時刻から本日/翌日を自動判定（数日先の予約も可能）
- 議題と割り振り時間を入力（↑↓で並べ替え）
- **今すぐ開始（再計算）**: 現在のJSTから終了時刻も計算し直す
- **今すぐ開始（終了維持）**: 予定終了時刻を固定して今すぐ開始（予定が2時間以上先・終了済みの場合は無効）
- **開始時刻まで待機**: 予定時刻まで待機し、遅れた場合は終了済みの議題をスキップ
- **超過表示**: 終了時刻を過ぎても自動終了せず、超過時間を表示。「会議を終了」で終了
- **+5分延長**: 現在の議題と以降の予定、会議終了を5分延長
- **会議を終了**: 会議中でも確認のうえ終了可能（終了時刻は実際に終了した時刻を表示）
- **結果をコピー**: 会議終了後に開始・終了・予定終了・議題結果をクリップボードへコピー
- **会議履歴**: 終了した会議の日時・予定/実績・議題を最大20件保存し、コピー・削除・全削除が可能
- テンプレート（標準・短縮・長期）を適用可能
- 設定のJSON書き出し・読み込みに対応
- 音声は最初の操作で有効化。必要に応じて「通知を有効化」を押す
- 対応ブラウザでは「アプリをインストール」でPWAとして追加可能
- 実行中は全画面表示で投影可能
- 同一タブで再読み込みした場合、実行状態を復元
- 対応ブラウザでは複数タブ同時実行を排他制御（Web Locks）

## アラームの制約

- クライアントサイドのみで動作します。タブを閉じた場合や端末がスリープした場合の鳴動は保証されません。
- 通知は対応ブラウザと許可が必要です。iOSではPWA/OSの制約があります。
- 音声が出ない場合は、実行画面の「音声を有効化」を押してください。

## 開発

- `npm install`
- `npm test`（Playwright）
- ローカルで直接確認する場合は `python3 -m http.server 8765 --directory public` などで配信してください（ES ModulesとService Workerのため`file://`では動作しません）
- CIではテスト成功後にGitHub Pagesへデプロイ

## デプロイ

- `.github/workflows/deploy-pages.yml` で `main` ブランチへのpush時に自動デプロイ
- GitHub Pages の Source は「GitHub Actions」
- PWAのService Workerでアプリ本体をキャッシュ（`public/sw.js`）
- 静的アセットはネットワーク優先で取得し、オフライン時はService Workerのキャッシュを使用
