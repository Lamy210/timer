# MTGタイマー

GitHub Pages: https://lamy210.github.io/timer/

日本時間（JST）基準のMTG用タイマーです。`public/` 以下をそのまま配信しています。

## 使い方

- MTG開始時刻、会議の長さ、開始前アラーム、終了前アラームを設定
- 開催日は任意。空の場合は開始時刻から本日/翌日を自動判定（数日先の予約も可能）
- 会議名・会議メモ（任意）を設定し、実行画面・履歴・コピー・JSONに反映
- 議題と割り振り時間を入力（↑↓で並べ替え）
- **今すぐ開始（再計算）**: 現在のJSTから終了時刻も計算し直す
- **今すぐ開始（終了維持）**: 予定終了時刻を固定して今すぐ開始（予定が2時間以上先・終了済みの場合は無効）
- **開始時刻まで待機**: 予定時刻まで待機し、遅れた場合は終了済みの議題をスキップ
- **超過表示**: 終了時刻を過ぎても自動終了せず、超過時間を表示。「会議を終了」で終了
- **延長（1〜60分）**: 現在の議題と以降の予定、会議終了を指定分延長
- **一時停止/再開**: 残り時間を凍結し、再開時に停止時間分だけ以降の予定を後ろへずらす
- **会議を終了**: 会議中でも確認のうえ終了可能（終了時刻は実際に終了した時刻を表示）
- **終了サマリー**: 予定/実績時間、終了時刻の超過・短縮、完了・スキップ件数を表示。結果コピーまたは設定に戻る導線を表示
- **結果をコピー**: 会議終了後に開始・終了・予定終了・議題結果をクリップボードへコピー
- **会議履歴**: 終了した会議の日時・予定/実績・議題を最大20件保存し、コピー・再利用・削除・全削除・JSON/CSV書き出し・JSON読み込みが可能。件数・平均実績・平均超過・スキップ数を表示し、各履歴の議題詳細も展開可能。会議名・議題・メモで検索可能
- テンプレート（標準・短縮・長期）を適用可能
- 設定のJSON書き出し・読み込みに対応
- 音声は最初の操作で有効化。必要に応じて「通知を有効化」を押す
- 対応端末ではアラーム時にバイブレーション
- 対応ブラウザでは、超過通知から「5分延長」「会議終了」を実行可能（アプリを開いている間）
- 通知アクション非対応のブラウザ（Firefoxなど）では、通知クリックでアプリを開いて画面から操作します
- 対応ブラウザでは「アプリをインストール」でPWAとして追加可能
- 実行中は全画面表示で投影可能
- 同一タブで再読み込みした場合、実行状態を復元
- 対応ブラウザでは複数タブ同時実行を排他制御（Web Locks）
- 実行中のキーボードショートカット: N(次へ) / B(戻る) / P(一時停止/再開) / E(延長) / F(会議終了) / M(音声切替) / Q(設定に戻る) / ?(ヘルプ)
- 実行画面の「?」ボタンでもキーボードショートカットを表示
- 開始方法の違いは折りたたみ式の説明で確認可能

## アラームの制約

- クライアントサイドのみで動作します。タブを閉じた場合や端末がスリープした場合の鳴動は保証されません。
- 通知は対応ブラウザと許可が必要です。iOSではPWA/OSの制約があります。
- Firefoxでは振動など一部APIが利用できない場合がありますが、タイマー・通知・PWAの基本動作は継続します。
- FirefoxのPWAインストール可否はブラウザ/OSの対応状況に依存します。
- 音声が出ない場合は、実行画面の「音声を有効化」を押してください。
- 複数タブの同時実行防止はWeb Locks対応ブラウザのみ有効です。
- Service Worker更新時に一時的に古いアセットが使われる場合があります。更新通知が表示されたら再読み込みしてください。

## 開発

- `npm install`
- `npm test`（Node単体テスト + Playwright / Chromium・Firefox・WebKit）
- `npm run test:unit`（純粋ロジックのみ）
- `npm run test:e2e`（ブラウザE2Eのみ）
- ローカルで直接確認する場合は `python3 -m http.server 8765 --directory public` などで配信してください（ES ModulesとService Workerのため`file://`では動作しません）
- CIではテスト成功後にGitHub Pagesへデプロイ

## 構成

- `public/app.js`: 起動・PWA・通知・設定/履歴の配線
- `public/js/run.js`: 実行制御・キーボード・実行画面イベント
- `public/js/run-alarms.js`: アラームスケジューリング・Wake Lock
- `public/js/setup.js`: 設定フォーム・議題・テンプレート・設定JSON
- `public/js/run-state.js`: 実行状態の更新（開始・復元・延長・スキップ・戻る）
- `public/js/run-view.js`: 実行画面の描画
- `public/js/history.js`: 会議履歴・CSV/JSON入出力
- `public/js/ui.js` / `result.js` / `time.js` / `alerts.js` / `storage.js`: 共通処理

## デプロイ

- `.github/workflows/deploy-pages.yml` で `main` ブランチへのpush時に自動デプロイ
- GitHub Pages の Source は「GitHub Actions」
- PWAのService Workerでアプリ本体をキャッシュ（`public/sw.js`）
- 静的アセットはネットワーク優先で取得し、オフライン時はService Workerのキャッシュを使用
